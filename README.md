# Verdana Protocol

Landing page for Verdana — Platform ESG & Carbon Monitoring untuk industri Indonesia.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui
- GSAP

## Development

```sh
npm install
npm run dev
```

Dev server runs at `http://localhost:9090`.

## Build

```sh
npm run build
npm run preview
```

## Deploy

Push to `main` on GitHub to trigger Vercel deployment.
